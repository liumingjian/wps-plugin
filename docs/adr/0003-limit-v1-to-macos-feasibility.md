# Limit V1 to the macOS feasibility path

V1 exists only to prove the end-to-end route on MJ's current macOS machine with Qaxbrowser and WPS: Native Messaging ping/pong, DOCX download and WPS launch, observation of a changed stable file, upload to the local Demo service, and verification of the uploaded edit. Customer-platform compatibility, page or service-worker recovery, background daemons, durable task state, locks, ETags, retry queues, formal installers, and other production hardening are deliberately deferred because they do not determine whether this route is feasible.
