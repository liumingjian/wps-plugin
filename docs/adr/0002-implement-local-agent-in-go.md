# Implement the local agent in Go

The local agent will be implemented in Go, prioritizing reliable development by AI coding agents, straightforward cross-platform builds, a mature standard library, and sufficient performance for file, process, JSON, and HTTP orchestration. Rust offers stronger low-level control, but that advantage does not justify its additional implementation and cross-compilation complexity for this workload; V1 will build only for macOS arm64 and add other targets only after the route is proven.
